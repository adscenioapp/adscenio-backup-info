# Adscenio Backups — public information

Static informational homepage and privacy notice for the administrator-only backup tool. No application code, archives, credentials or keys belong in this public repository.

## Publish after merging

1. Open Settings → Pages.
2. Select **Deploy from a branch**.
3. Select branch **main**, folder **/ (root)**, then Save.
4. Wait for GitHub's Pages deployment to finish and confirm both pages open over HTTPS.

Expected URLs (available only after deployment):
- Homepage: https://adscenioapp.github.io/adscenio-backup-info/
- Privacy: https://adscenioapp.github.io/adscenio-backup-info/privacy.html

## Google OAuth Branding

Use the live homepage and privacy URLs above. Authorized domain: `adscenioapp.github.io` (no protocol or path).
No logo or terms URL is required for this informational site unless Google specifically requests it.
Return to Audience and publish the OAuth app once Branding is accepted. If Google requests domain ownership verification, complete the actual verification; do not substitute an unrelated domain or placeholder URL.
The OAuth publishing status does not publish backup data.

The site's only public contact address is adscenio.app@gmail.com, matching the configured OAuth support contact.

## Maintenance

Buildless HTML and CSS. No JavaScript, cookies, external fonts, analytics or third-party assets. Relative internal links support the GitHub Pages project path. Review privacy statements whenever the backup implementation changes.
